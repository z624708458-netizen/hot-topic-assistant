# Demo 验收结果

在当前云环境中，通过真实 Chromium 浏览器执行 `python3 tests/test_demo.py`：7 项测试全部通过。

1. 五条候选排序、五维权重计算、历史时效性为零、发布日期、三个标题、稿件长度、来源链接。
2. 公司与关键词筛选、空结果、最近 24 小时排除历史样例、平台表达提示。
3. 收藏刷新后保留、收藏页详情导航、口播与标题复制、评分说明与来源目录。
4. 手动录入、刷新后保留、最近 24 小时评分、输入 HTML 按文字显示（不执行脚本）。
5. 拒绝非 HTTP(S) 来源链接与未来发布日期。
6. 390px 手机布局无横向溢出、详情操作、录入弹窗、静态资源可用；页面运行不发出第三方请求。
7. 损坏的本地存储不会阻止页面启动。

所有测试均检查未产生浏览器 JavaScript 异常。实际预览服务返回 HTTP 200；已查看桌面、手机截图。

五条示例稿分别为 378、415、433、415、409 字，按每秒 5–6 字估算约 63–87 秒。实际时长需朗读确认。

## 未完成的外部验证

- 当前出站代理拒绝官方新闻网站请求（403），官方链接内容及当前可访问性未在线验证。页面已注明，不宣称完成来源核验。
- 当前云端 Chromium 的管理策略拒绝 `file://` 地址（ERR_BLOCKED_BY_ADMINISTRATOR），双击 HTML 的路径无法在此浏览器中验收；已验证通过本地 HTTP 加载的同一静态文件及无外部资源依赖。普通个人电脑浏览器通常可直接打开；企业受管浏览器可能需要本地 HTTP 服务。

第一阶段不抓取当天新闻、不调用 AI/API、不生成公共部署链接。历史样例与用户提供的新闻明确分开，评分及创作稿件需人工核验。
