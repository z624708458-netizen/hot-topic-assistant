## 实际限制

公开 RSS 提供的标题、日期和摘要不等于独立事实核查。传闻/曝光保留标记。评分只匹配词语，不理解否定、语境或真实热度。口播是待填写事实的60–90秒框架，不能直接作为已核验的成稿发布。

本地验收不等于 GitHub Actions 与线上发布验收；部署是否成功以实际工作流与线上内容检查为准。首次运行的七天数据只覆盖各 RSS 当前提供的内容，之后逐步积累。
