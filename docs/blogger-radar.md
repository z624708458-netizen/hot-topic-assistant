# 博主雷达 V1 使用与接通说明

## 当前能使用什么

左侧 **博主雷达** 是独立页面，沿用现有视觉。无需注册新服务就能手动添加博主、补充主页、选择多个领域、粘贴作品链接和自己的笔记、关注/取消关注/忽略、按领域筛选、JSON导出/导入/恢复。

自动发现不提供样例填充。当前没有抖音应用凭据和授权，真实自动发现人数是 **0**。没有OpenAI配置时，AI拆解明确未连接，仍可查看作品和粘贴文字。不影响新闻、第二大脑、口播草稿及旧Worker接口。

## 官方能力：已准备与尚未接通

| 能力 | 本版状态 | 限制 |
| --- | --- | --- |
| 热门视频榜 `/data/extern/billboard/hot_video/` | 已编写服务端适配、规范化、领域筛选及发现流程；仅模拟测试通过 | 实际权限、字段和请求契约须按当前官方文档核对；未做真实调用 |
| 热点词 / 上升词 / 按词查热点视频 | 未启用 | 当前环境无法访问官方文档，不能猜测接口路径、参数或Scope |
| 全站视频搜索 | 未启用 | 必须实际获得对应权限并核对开放状态；品牌关键词管理不是通用搜索 |
| 评论内容、完整字幕、账号全部作品监控 | 不提供 | 评论数量不是评论内容；标题不是字幕；关注不是监控权限 |

参考官方资料（由任务提供；本次文档请求被环境网络403拦截）：

- [查询热点视频能力](https://developer.open-douyin.com/capacity-center-page/capacity-detail/7180573594794065975)
- [热门视频榜](https://open.douyin.com/platform/resource/docs/openapi/data-open-service/tops-data/hot-video-list/hot-video-list/)
- [可选视频搜索](https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/douyin-search-capability/aweme-dy-video-search)

**本版不宣称已完成上述官方文档的在线核对。** 适配器仅预置任务明确的热门视频榜路径与Scope，以及待核对的client_token交换与字段映射；模拟响应是测试契约，不是已捕获的官方响应。正式启用前必须核对当前应用文档/响应，特别是token请求头、列表容器、作者ID含义、字段可用性与数据保留限制。如果实际返回结构不同，接口停止解析并明确报错，不用替代数据冒充成功。

完整目标是“热点词 → 领域筛选 → 相关视频 → 作者去重 → 评分 → 最多30人”。在热点词能力未验证前，V1只准备 **已获批热门视频榜 → 标题/热度词筛选 → 作者 → 去重/评分** 的有限覆盖替代路径。它可能没有符合四个领域的作品，不能覆盖全站，也不保证发现30人。页面不会把它称作实时全站发现。

## 接通需要做什么

当前不自动注册抖音应用、不申请权限、不启用付费服务、不发送真实API请求。用户后续需要在官方开放平台确认应用资质、开放状态和具体权限；申请不保证通过。已有Cloudflare账号不等于已有抖音开放平台授权。

热门视频榜需要任务所列Scope：`data.external.billboard_hot_video`。热点词、上升词、按词查视频和可选搜索的Scope必须从当前官方文档及应用后台核对，不预填猜测名称。

确认权限后，由开发者核对官方响应与 `server/douyin-provider.js`，再在已有Worker Settings → Variables and Secrets配置：

| 名称 | 类型 | 用途 |
| --- | --- | --- |
| DOUYIN_CLIENT_KEY | Secret | 已获批抖音应用标识，只在服务端 |
| DOUYIN_CLIENT_SECRET | Secret | 抖音应用密钥，只在服务端 |
| APP_ACCESS_TOKEN | Secret | 至少24字符应用访问码，沿用原Worker认证；与任何平台Key不同 |
| DOUYIN_SCOPES | 文本 | 仅填写应用实际获批的 `data.external.billboard_hot_video` |
| DOUYIN_DATA_POLICY_CONFIRMED | 文本 | **完成当前官方请求契约、字段、展示与保留规则核对后**才能设为 `true` |
| DOUYIN_ENABLED | 文本 | 最后再设 `true`；默认为关闭 |
| ALLOWED_ORIGIN | 文本 | 沿用 `https://z624708458-netizen.github.io`，不含仓库路径 |

`DOUYIN_*`开关独立于`MODEL_ENABLED`，无需OpenAI即可使用已授权的官方数据。抖音Secret与OpenAI Key都不能填在网页、仓库、localStorage或聊天里。网页只填写Worker地址和**应用访问码**（仅当前页面内存，刷新需重填）。状态接口只检查配置，不验证真实权限；真正发现成功才说明该次榜单请求通过。

## Worker 路由

- `GET /douyin/status`：公开配置状态，无平台或模型调用，不返回密钥。
- `GET /douyin/discover`：服务端获取client_token，读取固定官方热门视频榜地址，规范化已返回作品，筛选四类领域、去重、最多30名；须已启用、权限已登记及应用访问码验证。未开通503，错误502，错误来源403，认证失败401，限流429。
- `GET /douyin/hot-videos`：同一授权保护，返回本次已规范化官方作品。最近24小时**离线**统计。
- `GET /douyin/hot-words`：明确返回503 `not_enabled`，无虚假词条、不调用未核对接口。
- `POST /blogger/analyze`：复用服务端OpenAI Provider边界，要求原有模型配置和应用访问码；只接收本条标题与用户粘贴文本，不读取视频链接。
- `/health`、`/generate`保持原V5.1契约。

不接受任意上游地址或通用搜索参数。沿用精确Origin、CORS、输入大小、模型超时、去敏和限流。官方发现独立限流每Worker隔离实例每IP每分钟4次；模型沿用每分钟10次。不是全局额度保证。client_token只在Worker内存短时复用，不输出、不持久化；没有浏览器Cookie、账号登录模拟或爬虫。

## 评分与缺失数据

- 领域40：从实际返回标题/热度词命中词库，1个不同词20分，每增加1词10，最高40；一个人可属于多个领域。
- 近期数量25：每条已发现且有日期、近7天的相关作品5分，最多25；不是账号全部产量。
- 互动20：已返回点赞＋评论＋分享合计S，`min(20, round(log10(1+S)*4))`；说明部分字段只是下界。不用未知播放量计算互动率。
- 活跃15：已知最近作品在24小时内15，3天内10，7天内5，之前0。没有发布日期就不评估。

显示 **已知得分 / 可评估上限**；缺维度不当零、不当满分、不归一化成虚假100。按已知得分优先、可评估上限次序排序。只能解释本轮候选优先级，不代表创作能力，也不预测爆款。

缺失字段一律“暂无数据”；真实0显示0。不推算粉丝、账号历史平均播放、未返回的日期或主页URL。作品每条注明接口、Scope、获取时间、实际返回字段、离线窗口和文字类型。未给作者ID/昵称的作品不凭空制造作者。稳定作者ID优先去重（仅本应用范围），没有ID时仅昵称+头像辅助去重并标低可信；只有昵称时按作品分开，避免把同名者强行合并。页面明确非身份认证。

## AI拆解

已连接模型时，需要用户粘贴至少30字、最多3万字的文案/字幕。一次点击发起一次OpenAI请求，**需要模型API额度**，不消耗假装存在的免费模型。只分析开头、观点、结构、文字情绪、争议、普通人利益和创作启发，不提供复制全文或搬运视频。

V1没有真实评论内容接口，因此“评论区需求”固定显示“暂无真实评论数据，无法分析评论区需求”；评论数不作为评论正文。分析边界说明没有观看视频、声音和画面，仅依据用户粘贴文字，事实需核对。未连接或失败不输出规则分析冒充AI。AI结果和临时粘贴文本仅在当前会话内存，不写第二大脑或旧口播草稿。

## 存储、备份与历史

唯一新增持久键：`radar-blogger-v1`，schema_version=1。仅保存用户选择的关注/忽略、最少账号引用（编号/用户可编辑昵称）、用户领域标签、手动主页/作品链接和笔记、页面筛选与服务地址。访问码不保存。不会写 `radar-brain-v4`、`radar-speech-v5` 或V3数据键。

**本版不长期缓存官方原始快照**：官方头像/封面/作品/互动/评分只在页面内存，刷新清空；同一次会话多轮发现保留已发现作品用于查看，不保证重开后历史仍在。关注记录不会把官方作品自动写入备份；手动引用会保留。正式启用前仍需核对平台是否允许会话展示以及最小关注引用，不能把“内存”当作豁免条款；如规则更严格，应继续关闭对应功能。

JSON导出仅包含上述用户数据。默认导入合并、去重，不覆盖当前关注/忽略决定；同一链接笔记冲突保留两个版本，重复导入不不断复制。整份校验通过后再一次写入；非法URL/日期/重复ID/超额/不合规文件整体拒绝。导入最多10MB、2000位作者、每人300条手动引用，浏览器实际容量可能更小。存储满时明确失败，保留当前输入；损坏原始数据保留，可先导出。

确需从备份恢复时，勾选“从备份恢复”，导入后确认替换**仅博主雷达数据**。其他模块数据不动。此选项不是默认导入行为。换设备需手动导出/导入，不自动云同步。

## 发布

GitHub Pages按原main流程更新。**Worker不会因推送GitHub而更新**。先运行：

```sh
node server/build-worker.mjs
node server/build-worker.mjs --check
```

然后按 [现有部署步骤](../server/README.md) 将 `server/worker.bundle.mjs` 的完整内容替换Cloudflare Worker并Deploy。该单文件含口播、博主雷达协议和两个Provider，不能只粘贴Douyin文件。保留已有Secret；不要删除/重置OpenAI设置，未启用的模型继续关闭。
