# 热点雷达 · 短视频热点选题助手

一个无需 API、无需安装依赖的网页版 Demo。纯 HTML / CSS / JavaScript，可离线打开。第一阶段用于体验完整的选题工作流，不是自动新闻采集服务。

## 不懂代码也能预览

下载项目文件（或 Demo 压缩包）并解压，双击 `index.html`，浏览器即可打开。请保留 `assets` 文件夹和 `index.html` 的相对位置。

## 开发预览

在仓库目录运行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

在本机使用浏览器打开 `http://localhost:8000`。如果命令运行在云机器上，需使用该平台提供的端口转发功能；这里没有自动生成公共网址。无需 npm install 或构建。

## 功能

- 五条附官方来源地址的真实历史新闻示例；明确标注历史日期，不伪装成当天热点。
- 公司、关键词、最近 24 小时筛选；筛选后的候选按综合分排序，最多显示 5 个。
- 大众认知度、争议性、反常识程度、利益相关性、时效性五维评分，公开权重和依据。
- 每条选题的推荐理由、切入角度、三个标题方向、约 60–90 秒的口播示范与复制功能。
- 手动录入新闻标题、公司、时间、来源、事实摘要，生成确定性规则评分与模板草稿。
- 收藏与录入数据保存在当前浏览器 localStorage，无后台上传；删除浏览器数据会清空。
- 响应式布局，可在电脑和手机浏览。

## 事实与限制

- 不调用大模型、不自动抓取新闻、不核验输入来源；没有购买 API 的要求。
- 历史示范采用人工编辑评分；历史事件时效性得分为 0。手动录入使用关键词规则，不能代表真实热度或客观结论。
- 最近 24 小时只按用户录入的新闻发布时间筛选；时间输入为北京时间（UTC+8），未来时间不接受。
- 公司筛选包含小米、华为、腾讯、字节跳动、阿里、百度、OpenAI、苹果、特斯拉。历史示例只覆盖部分公司，其余可自行录入。
- 官方来源地址在当前环境受到出站网络策略限制，未在线复核。发布前必须自行打开原文核验事实、数据、日期、条件及链接可访问性。
- 口播时长按每秒 5–6 字估算，需要实际朗读。长篇输入可能生成超过 90 秒的草稿，需精简。
- 平台选项改变表达提示，第一阶段没有为各平台生成独立稿件。
- 不构造不存在的新闻；草稿中的观点与提问不是原报道事实。请不要将历史样例当作当天新闻发布。

## 文件

- `index.html`：页面结构
- `assets/style.css`：响应式视觉样式
- `assets/app.js`：示例内容、评分、筛选、草稿、收藏与录入交互
- `tests/test_demo.py`：真实 Chromium 浏览器验收测试（需 Python Playwright 与 Chromium）

## 测试

在仓库目录运行（测试自动启动临时本地 HTTP 服务，不依赖运行中的预览服务）：

```sh
python3 tests/test_demo.py
```

测试覆盖候选排序、五维评分、标题与口播、收藏持久化、公司与时间筛选、新闻录入、来源链接与脚本注入防护，以及手机布局和浏览器错误。
